# JavaScript Full Stack

Este repositório reúne minha jornada de estudos em JavaScript, desde os fundamentos até o desenvolvimento Full Stack.

O objetivo é praticar programação, desenvolver projetos e acompanhar minha evolução como desenvolvedora.

## Objetivos

- Fortalecer minha lógica de programação.
- Aprender JavaScript do básico ao avançado.
- Desenvolver aplicações Front-end e Back-end.
- Trabalhar com bancos de dados e APIs.
- Criar projetos para meu portfólio.

## Organização dos estudos

| Mês | Conteúdo |

## Como estou estudando

Estou seguindo uma trilha de aprendizado com explicações, exemplos, exercícios e projetos práticos.

Os códigos deste repositório representam atividades desenvolvidas durante meus estudos.
