# Semana 01 — Variáveis e Condicionais

Nesta semana, pratiquei os primeiros conceitos de JavaScript, trabalhando com variáveis, operações matemáticas e estruturas condicionais.

## Conteúdos

- Declaração de variáveis com `let` e `const`.
- Tipos de dados.
- Operadores matemáticos.
- Estruturas condicionais com `if` e `else`.
- Exibição de informações com `console.log()`.

## Exercícios desenvolvidos

1. **Cadastro:** utilização de variáveis para armazenar dados de um cliente.
2. **Calculadora:** realização de operações matemáticas.
3. **Sistema de aprovação:** verificação de aprovação de acordo com a nota.
4. **Sistema de compra:** cálculo do valor total e aplicação de desconto.

## Objetivo da semana

Entender como armazenar informações, realizar cálculos e criar condições para que o programa tome decisões.

## Aprendizado

Os exercícios ajudaram a praticar a lógica de programação e entender como os comandos básicos de JavaScript funcionam.
