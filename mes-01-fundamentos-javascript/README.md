# Mês 01 — Fundamentos de JavaScript

Neste mês, o foco é revisar e fortalecer os conceitos fundamentais de JavaScript, desenvolvendo a lógica de programação e a capacidade de resolver problemas com código.

## Conteúdos estudados

- Variáveis (`let` e `const`)
- Tipos de dados
- Operadores matemáticos e de comparação
- Estruturas condicionais (`if`, `else`)
- Laços de repetição
- Funções
- Arrays e objetos
- Métodos de arrays

## Organização

- **Semana 01:** Variáveis e estruturas condicionais.
- **Semana 02:** Laços de repetição e funções.
- **Semana 03:** Arrays e objetos.
- **Semana 04:** Projeto prático.

## Objetivo

Ao final deste mês, quero conseguir utilizar os principais recursos da linguagem JavaScript e resolver exercícios básicos sem depender de soluções prontas.
